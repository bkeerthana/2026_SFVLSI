Perl File Handling with VLSI - Code Snippets and Activities

How to run:
1. Extract the ZIP file.
2. Open terminal inside perl_vlsi_filehandling.
3. Run examples using:
   perl 01_read_count/01_read_signals.pl

Notes:
- Each Perl file contains activity questions as comments.
- Sample VLSI-style input files are inside the inputs folder.
- Output reports are generated inside the output folder.

Suggested order:
1. Read and count signal files
2. Extract and write clock/reset reports
3. Read Verilog files
4. Process synthesis logs
5. Parse area and timing reports
6. Pass filename using command-line arguments
7. Mini project: VLSI summary generator
