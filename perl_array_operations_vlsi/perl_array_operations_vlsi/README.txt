Perl Array Operations - Code Snippets and Activities for VLSI Students

How to run:
1. Extract the ZIP file.
2. Open terminal inside perl_array_operations_vlsi.
3. Run examples using:
   perl 01_basics/01_create_access_array.pl

Notes:
- Each Perl file contains activity questions as comments.
- Examples use VLSI-friendly data such as signal names, module names, cell names, and slack values.
- The mini project generates output/classified_signals.txt.

Suggested order:
1. Create and access arrays
2. Loop through arrays
3. Add and remove elements
4. Count, sort, reverse, and slice arrays
5. Search and filter using grep
6. Convert between strings and arrays using split/join
7. Mini project: classify VLSI signals
